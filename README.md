# Control de Café

Aplicación web para registrar consumo diario de cápsulas mediante dos controles:
1. vasos + tazas lavadas;
2. cápsulas restantes en el dispenser.

Los datos del mes se guardan localmente en el navegador mediante localStorage.
Usá "Exportar respaldo" al cerrar cada mes.

## Publicación
Subí `index.html` y `manifest.webmanifest` a un repositorio de GitHub y activá GitHub Pages.
Luego abrí la URL desde Safari en el iPhone y usá Compartir → Añadir a pantalla de inicio.
